03 / Echo · AI-assisted clinical trial matching · Dr. Hua Xu’s lab

When AI builds the cohort, who checks it?

Echo’s LLMs draft both the cohort and the evidence. I designed a human checkpoint for each stage.

  1. Eligibility criteria
  2. LLM drafts SQL
  3. Checkpoint 01
  4. LLM extracts evidence
  5. Checkpoint 02
  6. Eligible patients

Checkpoint 01 · Visual steering

Is the cohort logic right?

The AI
Translates each criterion into SQL on the OMOP CDM.
The risk
One monolithic query hides criterion-level errors.
My design
Editable criteria graph, live counts, per-node SQL.

Checkpoint 02 · Chart review

Is each patient’s evidence right?

The AI
Extracts study variables, with a confidence per answer.
The risk
Uniform emphasis hides low-confidence results.
My design
Neutral table that flags only uncertain results.

04 / Echo · Checkpoint 1 · Visual steering · IEEE VIS 2026

Make the cohort logic inspectable

Four alternative cohorts · synthetic EHR data

Goal · Inspectable

AGraph, not checklist

Criteria flow down from the dataset, with patient counts on every node.

Goal · Refinable

BSQL beside every node

The LLM drafts it. The researcher’s edit becomes the source of truth.

Goal · Comparable

CCompare in lockstep

Overlap, profile, and insights all follow the graph.

Co-equal first author · IEEE VIS 2026

My roleEnd-to-end research, design, frontend, and evaluation. Collaborators built the backend and SQL agent.

04b / Echo · Checkpoint 1 · deep dive

Under the hood: analysis, build, evaluation

Evaluation

2 experts

90-minute sessions

Clinical oncology faculty and a clinical-trials data scientist, on synthetic MIMIC-IV in OMOP CDM. Both built and compared cohorts.

Limits we found

  • Concept mappings still need human checks
  • Splitting criteria into nodes is manual
  • Complex queries run slowly
